# 🛡️ Yash Chavan — 3D Cyber Security Portfolio

> A cinematic 3D portfolio with interactive Three.js scenes, unique section transitions, and multi-language support.

**🌐 [Live Portfolio](https://yashchavan-portfolio.vercel.app)**

---

## ✨ Features

- **3D Globe Intro** — Wireframe globe animation with zoom-through transition
- **Cinematic Transitions** — 5 unique scroll-triggered transitions (glitch, particle burst, 3D flip, terminal scan, signal wave)
- **Interactive 3D Scenes** — Unique Three.js backgrounds for every section
- **Typewriter Terminal** — Cyber command animation on the hero section
- **5-Language i18n** — English, Hindi, Japanese, Spanish, French
- **JLPT N5 & N4** — Japanese language proficiency certifications
- **6 Projects** — Showcased from GitHub with 3D card effects
- **5 Certifications** — Including HP Cyber Security & JLPT
- **Contact Form** — Mailto integration with social links
- **Fully Responsive** — Works on all devices

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Framework | React 18 + Vite |
| 3D Engine | Three.js + React Three Fiber |
| Styling | Tailwind CSS |
| Animation | Framer Motion |
| Icons | Lucide React |
| Deployment | Vercel |

## 🚀 Getting Started

```bash
# Clone the repo
git clone https://github.com/yashchavan24/yash-portfolio.git
cd yash-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
